# Mang kepweng #

"Mang Kepweng" most commonly refers to a Filipino fantasy comedy film franchise starring **Vhong Navarro** known for a magical red bandana that has healing powers. The franchise includes the 2017 film Mang Kepweng Returns and the 2020 sequel, Mang Kepweng: Ang Lihim ng Bandanang Itim, which follows the protagonist as he fights evil forces. The original character and story also date back to a 1979 film starring the late Chiquito.
